# 🚀 Instalação

### 1.

Baixe a versão mais recente:

➡️ https://github.com/confiei/HustFofin/releases/latest

### 2.

Execute o instalador `.exe`

### 3.

Abra o aplicativo e configure suas opções

### 4.

Acesse todas as ferramentas pelo menu lateral

# ❓ FAQ

<details>
<summary><b>O aplicativo é seguro?</b></summary>

<br>

O projeto possui código-fonte disponível para análise. Sempre revise o código antes de utilizar qualquer ferramenta que tenha acesso à sua conta ou dados locais.

</details>

<br>

<details>
<summary><b>Preciso instalar dependências?</b></summary>

<br>

Não. O instalador já inclui os componentes necessários para executar o aplicativo.

</details>

<br>

<details>
<summary><b>Quais sistemas são suportados?</b></summary>

<br>

Atualmente disponível para **Windows**.

</details>
