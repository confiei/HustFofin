## 🚀 Começando

1. Baixe o App na [página de releases](https://github.com/iwonw/HustFofin/releases/latest)
2. Execute o `.exe`
3. Adicione seu token do Discord
4. Conecte a conta e acesse as ferramentas pelas tab

> [!TIP]
> O **Token Finder** pode encontrar automaticamente tokens salvas no seu Windows — você não precisa procurar manualmente.

## ❓ FAQ

<details>
<summary><b>É seguro usar?</b></summary>
<br>
O HustRich é 100% seguro para uso. Nenhum dado é enviado para servidores externos. Você pode verificar isso no código-fonte. Porém, o uso de self-bots pode resultar em banimento da sua conta Discord, mas usamos timeouts que não vão acontecer nada com a sua conta, pode ficar tranquilo.
</details>

<details>
<summary><b>Preciso ter algo instalado para rodar e usar?</b></summary>
<br>
Não. O instalador já inclui tudo que é necessário para rodar o aplicativo.
</details>

<details>
<summary><b>Como consigo meu token Discord?</b></summary>
<br>
Use o <b>Token Finder</b> Dentro do App — ele encontra automaticamente tokens salvas no sistema. Alternativamente, você pode pegar seu token manualmente pelo DevTools ou usando alguma extensão na WebStore do Discord. Recomendo: https://chromewebstore.google.com/detail/extrator-de-token-discord/fmbogdbbnoajddoljpoefmnknheljcah
</details>

<details>
<summary><b>Como faz para Atualizar?</b></summary>
<br>
Não será preciso, ele irá buscar atualizações na página de release e vai atualizar automaticamente quando disponível.
</details>

<summary><b>Devices</b></summary>
<br>
Apenas para Windows
</details>
